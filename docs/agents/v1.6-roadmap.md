# DOTS v1.6 roadmap

Local-first agent orchestration. Phases are **release gates**, not parallel
wishlists.

## Status

| Phase | Focus | Status |
|-------|-------|--------|
| Phase 1 | Foundation (Pi, LiteLLM, scout, expert, budget, ledger) | **implemented** |
| Phase 2 | Trust / isolation (sandbox, worktrees, env, MCP trust) | **implemented** |
| Phase 3 | Eval-driven routing | **implemented** |
| Phase 4 | OpenRig orchestration | **implemented** |
| Phase 5 | Autonomous recovery / observability | **implemented** |
| Final | CI / release convergence | **in progress** |

## Evidence labels

| Label | Meaning |
|-------|---------|
| **PROVEN** | Exercised end-to-end with evidence |
| **CONFIGURED** | Files / merge / desired-state present |
| **MOCKED** | Deterministic tests without paid / live providers |
| **DEFERRED** | Explicitly out of scope until a later phase |

## Phase 1 — Foundation

Pi, LiteLLM, model-scout, expert, budget, ledger, local-first harness.

## Phase 2 — Trust and isolation

```text
Pi sandbox / permission policy
safe filesystem boundaries
network policy (bash vs model vs MCP)
secret isolation + env allowlists
Git worktree execution
MCP Inspector (diagnostic)
fail-closed safe mode
```

## Phase 3 — Evidence-based routing

```text
dots agent eval
model capability benchmarks
task-class success history
expected-cost routing
quality-floor calibration
```

Target: `expected task cost = estimated request cost / estimated success probability`.

## Phase 4 — OpenRig orchestration

First-class `openrig` component, Pi seat projection, `dots-pair` /
`dots-triad` / `dots-investigate`, Herdr views, team budgets, queue wrappers,
restore-check.

## Phase 5 — Autonomous recovery and observability

```text
guarded autonomy (default)
structural failure fingerprints
bounded recovery ladder
expert packet deduplication
checkpoints / resume (allowances preserved)
offline replay (zero network / mutations / billable)
inspect / timeline / failures / attention / metrics / cancel
```

See [autonomy.md](autonomy.md).

## Stretch (not mandatory for initial v1.6)

Multi-model voting, debate, OpenRouter Advisor, consensus/fusion, Claude
component, remote OpenRig workers.

## Final CI note

Release convergence pushes the accumulated feature branch, watches GitHub
Actions, and iterates until green before tagging **v1.6.0**.
