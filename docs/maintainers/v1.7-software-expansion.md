Phase 0 authored this roadmap. It reconciles ~100 proposed capabilities against the **actual** DOTS package architecture so later phases do not re-architect the program. Phase 1 extends package group `dev` and adds `./dots check` local validators (see `docs/using/local-ci.md`).

---

## 1. Verdict of recon

DOTS already ships a mature package-group control plane (`configs/packages/groups.toml`, `brew/groups/*.Brewfile`, Linux maps, profile `packages = […]`, `omit_from_all` components). Roughly **one third** of the candidate catalog is **already owned**. v1.7 should **extend** that model — not invent a parallel ownership path.

**Do not create a separate `ci` group.** Local CI tools already live in group **`dev`**.  
**Do not create `geospatial`.** Use existing **`geo`**.  
**Do not recreate `media` / `security` / `network` / `data`.** Extend them.  
**Do create** narrowly justified new groups: **`containers`**, **`k8s`**, **`backup`**, **`hardware`**, **`docs`**.

## 2. Current architecture (authoritative)

### 2.1 Package groups today

| Group | Purpose | Notable members |
|-------|---------|-----------------|
| `core` | Portable essentials | bash, zsh, git, jq, ripgrep, fd, fzf, neovim, … |
| `modern` | Ergonomic CLI | bat, lazygit, gh, just, uv, yq, … |
| `workstation` | Desktop CLI helpers | ranger, chafa, poppler, … |
| `infra` | Containers / k8s / Terraform today | docker*, helm, k9s, terraform |
| `media` | Image/video | ffmpeg, imagemagick, exiftool |
| `gui` | macOS fonts | JetBrainsMono Nerd Font |
| `server` | Headless extras | htop |
| `dev` | Local CI / lint | **act, actionlint, pre-commit, hadolint, mkcert**, … |
| `security` | Secrets / SBOM / signing | **gitleaks, trivy, sops, age, syft, grype, cosign, osv-scanner, semgrep** |
| `network` | Network / remote / k8s context | **tailscale, mosh, rclone, bandwhich, gping, stern, kubectx**, … |
| `data` | Tabular analytics | **duckdb, qsv, visidata, miller, jless** |
| `geo` | Geospatial CLI | **gdal, tippecanoe, pmtiles** |

### 2.2 Profiles today

| Profile | Groups | Notes |
|---------|--------|-------|
| `base` | core, modern | Minimal |
| `work` | + workstation, dev, data, geo, security, gui | **No** infra/network/media by default |
| `home` | + infra, media, gui, dev, network, data, geo, security | Broad workstation |
| `server` | core, modern, server | Headless; herdr component only |
| `all` | workstation set + dev/security/network/data/geo | Skips `omit_from_all` components |

### 2.3 Components relevant to this expansion

| Component | Relevant installs | `omit_from_all` |
|-----------|-------------------|-----------------|
| `mactools` | **orbstack, raycast, qgis**, ghostty, creative casks, … | **yes** |
| `ai-server` | docker/compose stack | yes |
| others | herdr, ollama, lsp, … | mostly no |

### 2.4 Install-only boundaries already documented

Tailscale, mkcert, SOPS/age/Cosign, rclone, difftastic/mergiraf — **install never activates**.  
`mitmproxy` is **intentionally omitted** today (consent surface); v1.7 may add it as **opt-in only**.

### 2.5 Platforms

Darwin (Homebrew), Debian/Ubuntu (apt), Fedora (dnf), Arch (pacman), Void (xbps). Empty map entry = SKIP for optional packages.
